# SWG Uprising Resource Price Calculator (DKD)
Live: https://holydog413.github.io/swg-price-calc/

Static page; `resources.json` is generated by `update_resources.py` from Galaxy Harvester (galaxy 161) and pushed (`python3 update_resources.py --push`). Galaxy Harvester sends no CORS headers, so the browser cannot fetch it directly.

Pricing: price = base × (avg of counted stats / 1000), base 22 by default, calibrated so a Small Generic Planet House (best current spawns, components costed recursively, 25% markup) sells for about 50,000 cr. Saved settings still at an old default of 500, 250 or 125 are migrated to 22 once; other settings are kept. The "Credits per unit (max stats)" box at the top of the page edits the same base price. Optional power curve and stat selection, saved in localStorage.

## Schematics tab
`schematics.json` is scraped from Galaxy Harvester's public schematic pages for galaxy 161 (ingredients, quantities, experimental stat weights) by `build_schematics.py` (~1,400 pages, ~1 req/s, cached in `.schem_cache/`). Schematics rarely change, so run it occasionally: `python3 build_schematics.py --refresh --push`. Resource group → type mapping comes from Galaxy Harvester's open-source seed data.

## Price lock
The base price fields (top box and Settings) and Reset defaults are PIN-locked. `index.html` contains only a random salt and SHA-256(salt + PIN), never the PIN. A correct PIN unlocks for the browser session (sessionStorage). This is a casual lock, not real security: a 4-digit PIN can be brute-forced from the hash, and the static page's code and localStorage can be edited by anyone.
